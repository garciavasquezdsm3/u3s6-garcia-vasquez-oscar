Sistema de Gestión de Servicios — Autenticación y Seguridad
Este repositorio contiene la entrega correspondiente a la Semana 6 de la Unidad 3 de la materia AplicaWeb. En esta etapa se implementa un sistema de autenticación propio utilizando django.contrib.auth, control de sesiones, aislamiento de datos por usuario y un checklist de seguridad para despliegue en producción.
